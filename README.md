# PhotoShuffle

Приложение для macOS 12+ (Intel и Apple Silicon): показывает фото и видео из папки со всеми подпапками в случайном порядке, находит на них людей, машины, животных и другие предметы, группирует лица и даёт подписать, кто есть кто. Всё распознавание идёт на самом Mac — фото никуда не отправляются.

## Как получить приложение

1. Загрузите все файлы проекта в этот репозиторий (включая скрытую папку `.github`).
2. GitHub сам соберёт приложение за 5–10 минут: вкладка **Actions** → зелёная галочка.
3. Откройте **Releases** (справа на главной странице репозитория) → последняя сборка → скачайте **PhotoShuffle.zip**.
4. Распакуйте и перетащите **PhotoShuffle** в «Программы».
5. Первый запуск: **правый клик → Открыть → Открыть** (приложение не подписано в Apple, это нормально).
   Если macOS пишет, что приложение повреждено, выполните в Терминале:
   `xattr -cr /Applications/PhotoShuffle.app`
6. Выберите папку с фото (можно весь внешний диск) и разрешите доступ к диску, если macOS спросит.

## Возможности

- Случайный показ фото, видео и Live Photo с плавными переходами и мягким наездом камеры.
- Фильтры: люди, конкретный человек, авто, животные, природа, море, еда, город, документы и сотни других предметов («Ещё»), годы, «В этот день», избранное.
- Раздел «Люди»: все найденные лица по количеству фото, подписи имён, «Это тоже Лёва?», объединение и исправление ошибок.
- Избранное и скрытие фото, «Показать в Finder».
- Анализ идёт в фоне, продолжается с места остановки и ждёт, если диск отключили.

## Клавиши в слайд-шоу

| Клавиша | Действие |
|---|---|
| Пробел | пауза / продолжить |
| ← → | предыдущее / следующее |
| F | в избранное |
| ⌫ | больше не показывать это фото |
| Enter или двойной клик | во весь экран |
| Esc | выйти из полноэкранного режима |

## Где хранятся данные

`~/Library/Application Support/PhotoShuffle/library.sqlite` — медиатека, лица и имена.
`~/Library/Caches/PhotoShuffle/faces` — миниатюры лиц (можно удалить, пересоздадутся).
